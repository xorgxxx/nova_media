# Nova Media

تطبيق Flutter (Android) يجمع ثلاثة أقسام محلية: **الفيديو** و**الصور** و**الموسيقى**، بهوية بصرية خاصة (لون مميز لكل قسم) وانتقالات سلسة.

## المميزات
| القسم | الوظائف |
|---|---|
| الفيديو | اكتشاف الفيديوهات المحلية، مشغل داخلي، سرعة التشغيل (0.25x–2x)، استكمال المشاهدة، قسم «تابع المشاهدة»، مفضلة، قوائم تشغيل، تشغيل تلقائي للتالي، نقر مزدوج للتقديم/الإرجاع 10 ثوانٍ، تدوير الشاشة |
| الصور | تصفح المجلدات، معرض كامل، عرض بملء الشاشة، تكبير بالقرص/النقر المزدوج، مفضلة، معلومات الصورة |
| الموسيقى | اكتشاف الملفات الصوتية، تشغيل في الخلفية، إشعار وتحكم من شاشة القفل، عشوائي/تكرار، قوائم تشغيل، مفضلة |

## التقنيات
Flutter + Dart، Riverpod (حالة)، `photo_manager` (MediaStore والصلاحيات)، `video_player`، `just_audio` + `just_audio_background`، `sqflite` (تخزين محلي).

## البناء (يدوياً، على جهاز Linux)
```bash
bash tool/install_toolchain.sh   # مرة واحدة: JDK17 + Flutter + Android SDK
source tool/env.sh
bash tool/build.sh               # bootstrap + analyze + test + build apk + verify
```
الناتج: `build/app/outputs/flutter-apk/app-release.apk`

> مجلد `android/` **لا يُرفق مسبقاً** عن قصد: `tool/bootstrap.sh` يولّده عبر `flutter create` بنفس إصدار Flutter المثبّت (لتفادي عدم توافق Gradle/AGP) ثم يطبّق عليه ملفات `android_overrides/`.

## حدود معروفة
- اسم الفنان/الغلاف للأغاني غير متاحين (MediaStore عبر photo_manager)؛ يُعرض اسم المجلد بدلاً منهما.
- التوقيع: الـ APK الناتج موقّع بمفتاح debug (مناسب للتثبيت المباشر، وليس للنشر على Google Play).
- على Android 14+ إذا اختار المستخدم «وصول جزئي» تظهر الملفات المختارة فقط.
